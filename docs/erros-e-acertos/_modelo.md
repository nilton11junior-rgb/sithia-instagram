# Modelo de entrada

Copie o bloco certo para o topo de `erros.md`, `acertos.md` ou `decisoes.md`.

## Erro

```
### AAAA-MM-DD · Título curto  `#tag`
- **O que aconteceu:**
- **Causa:**
- **Impacto:**
- **Como corrigimos:**
- **Como evitar daqui para frente:**
- **Envolve:** (post, arquivo ou ferramenta)
```

## Acerto

```
### AAAA-MM-DD · Título curto  `#tag`
- **O que fizemos:**
- **Resultado:** (de preferência com número: alcance, salvamentos, tempo poupado)
- **Por que funcionou:**
- **Como repetir:**
```

## Decisão

```
### AAAA-MM-DD · Título curto  `#tag`
- **Contexto:**
- **Opções consideradas:**
- **Escolha:**
- **Motivo:**
- **Revisar quando:**
```
