# Erros e Acertos

Memória do projeto. Tudo que deu certo, errado ou foi decidido fica registrado aqui, para não repetirmos erro nem perdermos o que funciona.

## Arquivos

| Arquivo | Para quê |
|---|---|
| [acertos.md](acertos.md) | O que funcionou e deve ser repetido |
| [erros.md](erros.md) | O que falhou, causa e como evitar |
| [decisoes.md](decisoes.md) | Escolhas tomadas e o porquê |
| [_modelo.md](_modelo.md) | Modelo para novas entradas |

## Regras de uso

1. Registrou algo? Use o modelo e coloque a entrada **no topo** do arquivo (mais recente primeiro).
2. Todo erro precisa de **causa** e **como evitar**. Erro sem prevenção vira erro repetido.
3. Todo acerto precisa de **por que funcionou**, para ser reaproveitável.
4. Inclua data (AAAA-MM-DD) e, se houver, o post ou arquivo envolvido.
5. Se um erro virar regra fixa, copie a regra para `CLAUDE.md` na raiz do projeto.
6. Antes de iniciar uma semana de conteúdo, leia `erros.md` por completo.
