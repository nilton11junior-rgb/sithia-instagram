# Design

Este projeto não tem interface web, então os critérios de UI e acessibilidade de site não se aplicam. O "design" aqui é a identidade visual dos carrosséis, que já está documentada em:

- **Identidade da marca** (cores, fontes, logo): `docs/marca/identidade-visual.md`.
- **Padrão das capas:** `docs/conteudo/padrao-visual-capa.md`. Pessoa de boca fechada, séria, palavra gigante atrás; aprovado em 09/10/2026.
- **Modelos de post:** `docs/conteudo/modelos-de-post/`.
- **Formato técnico:** 1080x1350 (4:5), de 2 a 10 slides, fontes Anton e JetBrains Mono em `marca/fontes/`, logo em `marca/assets/logo.png`.

Legibilidade conta como "acessibilidade" do post:
- texto do slide curto (no máximo 2 linhas no destaque);
- contraste alto sobre a foto, com o degradê escuro dos renders;
- nada de informação importante só na imagem: a legenda repete o essencial.
